# eat-before

A utility application to help track food expiration dates and remind you to eat items before they expire.

## Features

- Track grocery and pantry items with expiration dates
- Categorize food items (dairy, produce, pantry, meat, etc.)
- Timely reminders and notifications before food expires
- Reduce food waste and save money

## Getting Started

### Prerequisites

- Modern runtime/environment depending on planned tech stack (e.g., Node.js / Python)

### Installation

Clone the repository:

```bash
git clone https://github.com/Shaurya214/eat-before.git
cd eat-before
```
